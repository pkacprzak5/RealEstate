Perform a strict review against the take-home brief.

## Review dimensions
Check:
- source choice credibility
- import story credibility
- normalized schema quality
- duplicate handling
- missing-field handling
- browse/search/details completeness
- TypeScript frontend quality
- vague-intent AI flow quality
- deployment readiness
- README quality
- 1-page reasoning document quality
- example user journeys quality
- demo readiness

## Output exactly
1. critical fixes only
2. short demo script
3. known limitations
4. final submission checklist
5. what to say in an interview about the tradeoffs

## Review stance
Favor honesty and defensibility over polish.
Call out overengineering immediately.
